# fitbot

Две тренировки по 10 минут в день: напоминания, отметки, вес, тесты, прогрессия.
Python 3.10+, aiogram 3, long polling, `progress.json` вместо БД.

## Файлы

    bot.py          хендлеры, рендер, клавиатуры, запуск
    config.py       настройки и пути, читает .env вручную
    storage.py      progress.json: атомарная запись + дебаунс
    program.py      загрузка программ, валидация, план на дату
    progression.py  уровень интервалов и лесенки упражнений (чистые функции)
    stats.py        серия, вес, недельный отчёт, график
    reminders.py    что пора отправить (чистая функция)
    validate.py     проверка данных перед рестартом
    program/*.json  программы, автоподхват при старте, порядок по полю order
    tests/          python tests/test_logic.py

## Установка

    adduser --system --group --home /opt/fitbot fitbot
    scp -r fitbot/* root@server:/opt/fitbot/
    cd /opt/fitbot && python3 -m venv venv && venv/bin/pip install -r requirements.txt
    cp .env.example .env && nano .env        # токен вписывать на сервере, не копировать с Windows
    chown -R fitbot:fitbot /opt/fitbot       # после каждой заливки
    cp fitbot.service /etc/systemd/system/ && systemctl daemon-reload
    systemctl enable --now fitbot

`ExecStartPre` гоняет `validate.py`: с битым JSON программы сервис не стартует, а в
`journalctl -u fitbot` будет причина.

## Как устроена нагрузка

- Интервалы: уровень = неделя программы + `shift`. Оценка 5 после утренней тренировки
  сдвигает на шаг назад, три подряд оценки 1-2 на шаг вперёд.
- Упражнения: у каждого лесенка `steps`, плановая ступень по неделям в `schedule`.
  Кнопки «Легче/Сложнее» меняют личное смещение этого упражнения, оно сохраняется.
- Второй месяц: положить `program/month2.json` с `"order": 2` и перезапустить.
  Бот переключится сам на следующий день после конца первого.

## Картинки упражнений

Папка `images/`, имя файла = id упражнения из программы: `squat.jpg`, `pushup.jpg` и т.д.
(jpg, png или webp). Если файл есть, на карточке упражнения появляется кнопка «Как делать»,
картинка приходит по нажатию и убирается при переходе к следующему упражнению.
Картинку под конкретную ступень лесенки можно положить как `<id>_<номер ступени>.jpg`
(нумерация с 0), она имеет приоритет над общей.

## Разовые тренировки (/quick)

Отдельно от курса: не влияют на серию и недельный отчёт. Формат AMRAP 10 минут:
круг из 4 упражнений, цель 4 круга, записываются круги и сложность 1-5.
База в `quick/exercises.json`: у упражнения группа (legs, push, core, cardio, back, mobility),
слоты, где оно уместно, ступени с дозой (`reps` или `sec`) и `schedule`: ступень для уровней 1-5.
Шаблон набора по слоту в `templates`. Уровень растёт после двух лёгких (1-2) тренировок подряд
с выполненной целью, падает при 5/5 или если кругов на 2 меньше цели.
